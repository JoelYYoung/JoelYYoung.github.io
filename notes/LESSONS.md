# Website design lessons

## Overall direction

- Keep the visual language restrained, academic, and consistent with the homepage biography and publication cards.
- Prefer neutral backgrounds, subtle borders, and a clear typographic hierarchy over gradients, saturated colors, or decorative effects.
- Support light and dark modes with equivalent contrast and visual weight.

## Typography

- Reuse the site's system sans-serif font stack; do not introduce a separate display font for individual sections.
- Keep project titles compact (`1.25rem`, bold) rather than reusing oversized page-heading styles.
- Use slightly smaller body copy with comfortable but controlled line height (`0.95rem`, `1.6`).
- Use weight and spacing to establish hierarchy before adding color.

## Project cards

- Keep project descriptions to one informative sentence.
- Do not add generic category labels such as “AI · Typst” or “AI · Learning” unless they help navigation or convey information not already apparent from the title and description.
- Use the same neutral card treatment for every project; avoid per-card gradients or competing palettes.
- Make the entire card clickable and keep the destination label short.
- Hover feedback should be subtle and consistent with the rest of the site.

## Icons and links

- Profile icons should share the same dimensions and hover behavior.
- Icon links should not inherit the standard text-link underline.
- Favicon artwork must remain legible at 16×16 pixels; prefer simple, high-contrast geometry.
